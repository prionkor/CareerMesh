# CareerMesh Product

CareerMesh is an AI-powered career intelligence platform.

## Core concepts

### Career data

The user's career data is the source of truth.

It includes:

- Profile
- Experiences
- Projects
- Skills
- Education
- Certifications
- Languages

### Job

A job represents an external opportunity.

### Resume

A resume is a representation of career data optimized for a particular
job or purpose.

A resume is not the source of truth.

### Application

An application represents a real application submitted to a company.

It records the exact resume and cover letter used.

## Core workflow

1. Career Data
2. Job Description
3. Job Analysis
4. Relevant Career Evidence
5. Resume / Cover Letter
6. Application
